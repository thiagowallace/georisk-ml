# GeoRisk ML

Pipeline geoespacial de Machine Learning para análise de suscetibilidade a movimentos de massa.

## Status

Projeto em desenvolvimento.

## Objetivo

Construir um pipeline reproduzível que integre dados geoespaciais públicos, processamento espacial, banco de dados e Machine Learning para análise de suscetibilidade a movimentos de massa.

## Tecnologias previstas

- Python
- Pandas
- NumPy
- GeoPandas
- Rasterio
- Scikit-learn
- PostgreSQL
- PostGIS
- SQL
- Streamlit
- Docker
- Git
